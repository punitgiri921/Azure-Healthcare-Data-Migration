🏛️ Project Architecture & Data Flow

This platform implements a hybrid cloud migration architecture connecting on-premises healthcare databases to Azure via a Self-Hosted Integration Runtime, processing data across Bronze, Silver (PII Masking), and Gold (Star Schema) layers in ADLS Gen2.

[ON-PREM EMR DB] -> (Local) -> [SHIR Gateway] -> (Outbound 443 HTTPS) -> [ADF Ingestion Pipeline] │ ▼ [Power BI App] <- [Synapse Serverless SQL] <- [Gold Marts] <- [Silver Clean/Mask] <- [Bronze Raw Parquet]
🔐 Enterprise Security & HIPAA Standards
  • Zero-Secret Deployment: ADF accesses Azure Key Vault and ADLS Gen2 via System-Assigned Managed Identity (SMI).
  • SHIR Outbound-Only: No incoming ports opened on the on-prem firewall. Gateway connects outbound to Azure on port 443.
  • HIPAA Safe Harbor De-Identification: SHA-256 cryptographic hashing applied to Social Security Numbers and patient names in the Silver layer.
  • Separation of Compute & Storage: Data sits permanently in low-cost ADLS Gen2 storage; Synapse Serverless compute spins up on-demand only when queries execute.
